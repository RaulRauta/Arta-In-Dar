# SEC-001 — Linkuri CMS fără allowlist de scheme-uri sigure

- Severitate: Medium
- Status: Confirmată
- CWE: CWE-79, CWE-601
- Componentă afectată: randare articole Sanity / Portable Text / CTA-uri noutăți
- Fișiere și linii:
  - `app/noutati/[slug]/page.tsx:31-36`
  - `app/noutati/[slug]/page.tsx:81-99`
  - `app/noutati/[slug]/page.tsx:236-254`
  - `app/noutati/[slug]/page.tsx:448-451`

## Descriere

Linkurile venite din Sanity (`href`, `linkHref`, `templateCtaHref`, `ctaHref`) sunt randate direct în `<a href>` sau `next/link` fără normalizare și allowlist explicit de scheme-uri. Pentru unele câmpuri schema folosește `type: "string"`, deci editorul poate introduce valori arbitrare.

## Condiții necesare exploatării

Atacatorul trebuie să poată modifica date în Sanity sau să compromită contul unui editor. Nu este exploatabil direct de un vizitator anonim.

## Source-to-sink

Sanity document field (`linkHref`/`templateCtaHref`/`ctaHref`/Portable Text annotation `href`) → `lib/news.ts` GROQ fetch → `app/noutati/[slug]/page.tsx` → JSX `href={...}`.

## Impact realist

Un editor compromis poate publica linkuri cu scheme-uri nedorite, inclusiv `javascript:` sau redirecturi/phishing. Impactul este click-based, dar public și persistent.

## Dovadă

Codul verifică doar `href.startsWith("http")` pentru a decide `target="_blank"`, nu pentru a valida siguranța URL-ului. Pentru valorile non-http se folosește `Link href={href}` sau `<a href={href}>`.

## Reproducere sigură

Pe un dataset de test, publică un articol cu un CTA `javascript:alert(1)` și verifică HTML-ul generat. Nu testa pe producție cu payload activ.

## Motivarea severității

Medium: necesită acces CMS, dar poate afecta vizitatorii publici și integritatea site-ului.

## Remediere concretă

Adaugă helper unic:

```ts
export function safeHref(value?: string) {
  if (!value) return null;
  const trimmed = value.trim();
  if (trimmed.startsWith("/")) return trimmed;
  try {
    const url = new URL(trimmed);
    return ["https:", "http:", "mailto:", "tel:"].includes(url.protocol)
      ? url.toString()
      : null;
  } catch {
    return null;
  }
}
```

Folosește helperul înainte de orice `href` venit din CMS. În Sanity schema, adaugă validare custom pentru aceleași reguli.

## Teste de adăugat

- Unit tests pentru `safeHref`.
- Test rendering pentru `javascript:`, `data:`, URL extern valid, path intern valid.

## Verificare după remediere

Scanare cod pentru toate `href={...}` din date CMS și test de randare cu valori nesigure.

## Incertitudini

Nu am modificat datasetul de producție și nu am publicat payloaduri reale.
