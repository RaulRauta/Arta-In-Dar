# SEC-005 — CSP compatibilă, dar nu strictă

- Severitate: Informational
- Status: Hardening aplicat parțial
- CWE: CWE-693
- Componentă afectată: headere globale și Studio
- Fișier și linii: `next.config.ts:37-51`, `next.config.ts:84-99`

## Descriere

CSP este prezentă și mult mai bună decât lipsa unei politici, dar folosește `script-src 'unsafe-inline'` pe site și `unsafe-inline`/`unsafe-eval` pe Studio pentru compatibilitate. Acest lucru reduce protecția CSP împotriva unor clase de XSS.

După hardening, politica blochează scripturile în atribute HTML prin `script-src-attr 'none'`, declară explicit `worker-src`, `child-src`, `manifest-src` și păstrează politici separate pentru site și Sanity Studio.

## Condiții necesare exploatării

Este necesară o vulnerabilitate XSS separată sau conținut malițios care ajunge în DOM.

## Source-to-sink

Header CSP generat în `next.config.ts` → browser.

## Impact realist

În cazul unui XSS, CSP ar limita mai puțin execuția decât o politică bazată pe nonce/hash.

## Dovadă

Headerul inițial de producție conținea `script-src 'self' 'unsafe-inline'`; Studio avea `unsafe-eval`. HTML-ul live conține scripturi inline generate de Next, deci eliminarea directă a `'unsafe-inline'` ar risca să rupă hidratarea aplicației.

## Reproducere sigură

Verificare headere:

```bash
curl -I https://arta-in-dar.vercel.app/
```

## Remediere concretă

Hardening aplicat:

- `script-src-attr 'none'` pe site și Studio.
- `style-src-attr 'unsafe-inline'` separat, pentru compatibilitate cu stiluri inline.
- `worker-src 'self' blob:`.
- `child-src` explicit pentru Google Maps.
- `manifest-src 'self'`.

Nonce/hash rămâne o opțiune viitoare, dar nu a fost adoptată acum deoarece ghidul Next.js precizează că nonce-urile cer randare dinamică și dezactivează beneficiile de static generation/CDN pentru paginile statice.

## Teste de adăugat

- Smoke tests vizuale pe toate paginile.
- Verificare CSP report-only înainte de enforce.

## Verificare după remediere

Confirmă că site-ul și Studio funcționează fără erori CSP în consolă. Verificările locale `npm run lint` și `npm run build` trec.

## Incertitudini

Next/Sanity necesită concesii de compatibilitate. Strict CSP cu nonce ar necesita o schimbare arhitecturală deliberată către randare dinamică sau o strategie hash/SRI matură.
